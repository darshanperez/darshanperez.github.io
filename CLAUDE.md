# Portfolio de Darshan

La especificación completa está en @docs/PORTFOLIO_SPEC.md. Síguela en cada tarea.

- Trabaja por fases (§15) y haz deploy a GitHub Pages al terminar cada una.
- Los tokens de diseño (§17) y de movimiento (§18) son la única fuente de valores visuales: no inventes colores, tamaños, duraciones ni curvas nuevas.
- Antes de empezar, verifica que las skills del "Paso 0" estén instaladas. Si falta alguna instalable por terminal (§0.2), instálala; si falta un plugin (§0.1), pídeme que escriba el comando `/plugin`.
- Si dos skills se contradicen, manda la especificación.
- Textos del sitio: siempre desde `public/i18n/strings.csv`, nunca escritos directo en el HTML o el JS.

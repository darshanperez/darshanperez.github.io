# Darshan's Portfolio

Single-page portfolio with a scroll-driven 3D intro (Three.js + GSAP ScrollTrigger + Lenis), built with Vite and deployed to GitHub Pages.

The full specification lives in [`docs/PORTFOLIO_SPEC.md`](docs/PORTFOLIO_SPEC.md).
